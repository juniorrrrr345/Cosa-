# 📚 Guide des Fonctionnalités

Documentation complète de toutes les fonctionnalités du bot.

## 👤 Interface Utilisateur

### Menu Principal (`/start`)
- Photo d'accueil personnalisable
- Message de bienvenue avec prénom
- Boutons de réseaux sociaux
- Accès aux informations et stats

### Réseaux Sociaux
- Liens directs cliquables
- Emojis personnalisables
- Organisation par paires

### Page Information
- Texte personnalisable
- Support HTML
- Idéal pour FAQ/règles

## 👨‍💼 Panel Administrateur

### Accès (`/admin`)
- Réservé aux admins
- Interface complète
- Suppression auto des messages

### Fonctionnalités Admin

#### 📝 Message d'accueil
- Modification en temps réel
- Variable `{firstname}`
- Support HTML

#### 🖼 Photo d'accueil
- Upload simple
- `/removephoto` pour supprimer

#### 🔗 Réseaux sociaux
- Ajouter : `Nom | URL | Emoji`
- Modifier et supprimer
- Ordre personnalisable

#### 📊 Statistiques
- Utilisateurs totaux
- Nouveaux par jour/semaine
- Historique 7 jours

#### 📢 Diffusion
- Messages à tous
- Support texte/photo/vidéo
- Rapport en temps réel

#### ⚙️ Paramètres
- Mode maintenance
- Suppression auto (admin uniquement)
- Stats publiques
- Diffusion on/off

## 💡 Conseils d'utilisation

### Bot de vente
- Photo : produit phare
- Message : offre + CTA
- Réseaux : shop, contact

### Communauté
- Photo : logo
- Message : bienvenue + règles
- Réseaux : Discord, groupe

### Support client
- Photo : logo entreprise
- Message : "Comment aider?"
- Info : FAQ, horaires
